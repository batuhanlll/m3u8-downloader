\# M3U8 Video Downloader \& Subtitle Embedder



M3U8 videolarını indirir, MP4 formatına dönüştürür ve VTT altyazısını videoya gömer.



\## Özellikler



\- M3U8 video indirme

\- Otomatik MP4 dönüştürme

\- VTT altyazı indirme

\- MP4 içine altyazı gömme

\- Özel dosya adı desteği

\- Referer desteği

\- Türkçe / İngilizce altyazı dili seçimi



\## Gereksinimler



\- Python 3

\- FFmpeg

\- yt-dlp

\- curl



\## Kurulum



pip install yt-dlp



\## Kullanım



python main.py



\## Çıktılar



Tüm dosyalar:



downloads/



klasörüne kaydedilir.
